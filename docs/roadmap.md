# Roadmap Journey Wallet

## Features

- [ ] JWF-1. Add spotlight search to the app
- [x] JWF-2. Have an opportunity to open app document storage where all docs in the folder will be shown. This does not depend on Document entity, this is for debugging purposes. The feature should be in Developer Section
- [x] JWF-3. Add entity "Idea" to the app. The Idea is similar to "PlaceToVisit" and there also should Title, Description, and url for video, instagram post, etc. The only title is required. The Idea also attached to Journey object.
- [ ] JWF-4. Plan roadmap: trip planning with cities and dates, and it should be available to attach travel objects to the cities, places, etc. Drag and drop should be available to sort cities and places. Roadmap should look like timeline with dots and lines. Each dot mean a city or place to visit. Lines might have transport attached. By default, timeline should show only short titles, but on tap it should show either transport or travel objects. The Timeline should be the third screen instead of Reminders screen. The timeline should be opened for selected Journey, and journey dropdown should be available to select journey at the top of the screen like it is done on the second screen of the app.
